# Финансовый дашборд

## Описание
Интерактивный веб-дашборд для анализа доходов и расходов.

## Функционал
- Линейный график (динамика расходов)
- Круговая диаграмма (структура)
- Гистограмма (распределение)
- Таблица данных
- Фильтрация по категории и дате
- Добавление и удаление записей

## Технологии
- Python
- Dash
- Plotly
- Pandas

## Запуск
```bash
python app.py
